Kryptonite

Créé par NightFury / softpython2884

Pourquoi ce projet ?

Architecture Backend

Concevoir une API REST robuste et réutilisable capable de traiter des requêtes de chiffrement à la volée.

Crypto Historique

Explorer et implémenter les algorithmes classiques : César, ROT13, Vigenère et le Carré de Polybe.

Montée en compétence

Maîtriser TypeScript en environnement Node.js strict et structuring d'un microservice moderne.

Challenges Techniques

Problème : Bouclage Alphabet

Comment gérer le décalage de 'z' vers 'a' ou les caractères spéciaux dans César/ROT13 ?

Solution : Utilisation de l'opérateur modulo : (index + shift) % 26.

Problème : Clé Vigenère répétitive

La clé doit se répéter pour correspondre à la longueur du texte.

Solution : Indexation cyclique : key[i % key.length].

Problème : Validation des entrées

Empêcher le plantage si l'utilisateur envoie des nombres au lieu de chaînes.

Solution : Middleware Zod pour rejeter les inputs invalides (400 Bad Request).
